# Archived source

These are the Stage 0.98–1.00 scripts recovered from the first-version workspace.

The Stage 0.99 and Stage 1.00 scripts intentionally read the frozen input trees under `src/outputs_stage098_refine120/` and `src/outputs_stage099_chariot_soil/`. Those small mirrored trees are included so the frozen screens can be rerun without silently substituting the later B0.5/B0.8 world.

The model is deterministic for the archived inputs. Re-running Stage 0.99 or Stage 1.00 is a replay of the declared screen, not a validation of ancient Ballah.
