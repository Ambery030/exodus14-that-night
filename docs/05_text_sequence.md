# 05 — 經文次序與模型時鐘

## 經文先後

這一版採取的最低次序是：

1. 夜間營地分隔／東風作用（Exodus 14:19–21）。
2. 以色列人進入並通過 sea-space，在水界之間行走（14:22）。
3. 埃及人追入 sea-space（14:23）。
4. 晨更時發生擾動（14:24）。
5. 車輪／駕駛出現困難，追兵決定撤退（14:25）。
6. 主要回水／覆蓋敘事（14:26–28）。

重要護欄：14:23 在 14:24 之前，所以不能把埃及人的進入直接放在天亮之後。另一方面，`morning watch` 不提供本模型可以合法指定的單一現代分鐘。

## 這個對照能支持什麼

它支持一個**次序相容的 parallel event**：路先開、以色列側先動；埃及人可在仍有 route 時進入；濕砂／重複交通先造成 mobility degradation；隊伍可能開始撤退；之後水路逐段復濕並關閉。

它不能單獨支持：

- 全部埃及人都被回水覆蓋；
- 戰馬推擠是唯一或主要死亡原因；
- 低能見度使所有追兵誤入深水；
- 06:40 是歷史上的精確黎明時間。

## 「乾地」的版本內定義

Stage 0.98 的 traffic gate 使用 firm sandy route、`h ≤ 0.10 m` 與 `h|u| ≤ 0.20 m²/s` 等操作性條件。這是程式的交通診斷，不是把經文的「乾」固定翻譯成 10 cm，也不是說整個湖盆都乾了。深水和 lateral water boundaries 仍保留。
